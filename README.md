## CIS 300 Project – DevTools Hub

DevTools Hub was created for my CIS 300 class project. The goal of this website is to help new programmers and students learn about useful development tools that make coding easier and more enjoyable. The site provides simple explanations, examples, and resources to help beginners understand how these tools work.

### Website Pages

- **Home** – Welcomes visitors, explains the purpose of the site, and includes a short introductory video.
- **Editors** – Describes popular code editors like VS Code and Sublime Text and explains how they help with writing and organizing code.
- **Version Tools** – Covers tools such as Git and GitHub and includes a basic cheat sheet for beginners.
- **Design** – Highlights tools like Figma and Canva used for creating layouts and graphics.
- **Resources** – Features a comparison table, helpful external links, and a tutorial video.
- **Contact** – Offers a simple form where visitors can submit feedback, questions, or suggestions.
